¿Cómo se organiza la galería de proyectos?

La rejilla define cómo respira el trabajo. Para portafolios gráficos el espacio y la jerarquía son tan importantes como las imágenes mismas.

A — Masonry editorial

Proyectos destacados ocupan más espacio. El featured dobla en tamaño. Ritmo orgánico, cada proyecto respira distinto según su peso visual.

✓ Muestra jerarquía
✓ Más editorial, menos template
✓ El trabajo featured domina
✗ Requiere curación del orden

B — Grid limpio 3 columnas

Todos los proyectos en igualdad. Foco total en la imagen. Clean, casi invisible como estructura — deja que el trabajo hable solo.

✓ Máxima limpieza
✓ Foco total en imagen
✓ Escala sin curación
✗ Sin jerarquía visual
✗ Puede volverse catálogo
01 Rebranding Empresa XYZ Branding
02 Identidad Editorial Editorial
03 Sistema de Packaging Packaging

C — Lista editorial horizontal

Cada proyecto como una fila con número, thumbnail, título y categoría. Muy tipográfico. Transmite confianza y orden, más cercano a un estudio senior.

✓ Muy tipográfico y editorial
✓ Toda la info de un vistazo
✓ Escala muy bien
✗ Thumbnail pequeño
✗ Menos impacto visual
