01 / Color · UI— Tokens semánticos

Tokens, no colores.

En producto nunca usamos un color directamente. Usamos tokens semánticos — --bg, --surface, --action — para que el sistema pueda cambiar (dark mode, alto contraste, accesibilidad) sin tocar componentes. Cada token tiene un único propósito.

Superficies y texto.

Cuatro niveles de superficie + tres de texto cubren cualquier layout web o móvil sin ambigüedad.

TokenValorUsoContraste

--surface#FFFFFFCards, modales, contenedores sobre --bg.vs text-1 17.6

--border-strongrgba 18%Bordes de inputs, botones ghost, divisores fuertes.decorativo

Acción, estado y feedback.

Brasa es nuestro color de acción. Nunca lo usamos para texto largo — sólo CTAs, énfasis y elementos interactivos. Los colores de estado tienen variantes soft para fondos de alertas.

TokenValorUsoEstado

--danger#EC3813Errores, eliminaciones, validación crítica.negativo
--info#011E54Notas informativas, tooltips densos.neutral

Cuándo NO usar color.

El color es un acento. Lo usamos para guiar la atención — no para decorar. Estas reglas son no-negociables:

  • · Nunca uses --action para texto de párrafo. Sólo CTAs, links, énfasis.
  • · Nunca uses más de un acento por pantalla en mobile. En web, máximo dos.
  • · Nunca codifiques significado únicamente por color — siempre acompaña con ícono o texto.
  • · Nunca uses --coral sobre --bg para texto. El contraste falla.

Una escala
para producto.

Reglas de aplicación.

No mezcles más de tres niveles tipográficos en una misma pantalla mobile. En web puedes llegar a cinco, pero no más.

  • · Cuerpo base mobile = 16 px (nunca menos para texto leíble).
  • · Touch target mínimo = 44 × 44 px. Aplica a botones, links interactivos, items de lista.
  • · Display (Fauna One) sólo en hero o portadas. En cards usar H3 con Manrope.
  • · Tabular numbers (font-feature-settings: "tnum") en tablas y montos.
03 / Layout— Espacio, grid, breakpoints

Todo cae
en una grilla de 4.

Toda separación, padding y margen respeta una escala de 4 pt. Los componentes tienen padding mínimo predefinido y nunca se "ajustan a ojo". Si necesitas un valor que no está en la escala, hay un error de diseño antes que un error de spacing.

9 escalones cubren cualquier caso. Tokens --sp-0 a --sp-9.

04 / Elevación & radios— Profundidad y esquinas

5 niveles
de elevación.

La sombra comunica jerarquía espacial: una card sobre el fondo, un menú sobre una card, un modal sobre todo. Cuac usa 5 niveles — más que eso es ruido.

el-0flat · separadores
el-1cards default
el-2cards hover, sticky
el-3menús, popovers
el-4modales, sheets

Radios de esquina.

Seis radios estándar. --r-pill para botones y badges; --r-md es el default para cards y inputs.

--r-00 · separadores rectos
--r-xs4 · tags pequeños, code
--r-sm6 · inputs, alerts
--r-md10 · cards default
--r-lg16 · modales, sheets
--r-pill999 · botones, badges
